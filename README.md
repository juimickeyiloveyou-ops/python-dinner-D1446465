## 3. 問答題回答

### 問題一：為什麼 ` "4" ` 要先轉成數字，才能用於本題的分攤計算？
**答：** 因為 `"4"` 在 Python 中是**字串（str）型別**，字串與數字之間無法直接進行除法運算（例如將總金額除以字串會引發 `TypeError`）。因此必須先透過 `int()` 函數將其轉換為整數型別，Python 才能正確進行數值計算並得出每人分攤費用。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
**答：** 
1. **計算過程與結果：**
   - 扣除折價券後的剩餘餐費：$1,200 - 100 = 1,100$ 元。
   - 依剩餘餐費計算服務費：$1,100 \times 0.10 = 110$ 元。
   - 應付總額：$1,100 + 110 = 1,210$ 元（比規定的 1,220 元少 10 元）。
2. **原因：**
   餐廳的計費常理與題目規則通常規定「服務費應以原餐點總價（未扣除優惠前）來計算」，因為餐廳服務成本是基於原本提供的餐點規模而定。若先扣除折價券再算服務費，會導致服務費的計算基數變小，進而使餐廳實際收到的服務費減少，這與一般商業邏輯與題目設定的「服務費必須以原始餐費計算」不符。
